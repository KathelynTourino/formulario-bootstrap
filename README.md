# Formulário - Mostra de Tecnologia e Inovação

## Objetivo

Este projeto consiste em uma página web com um formulário de inscrição
para uma Mostra de Tecnologia e Inovação.

O objetivo foi praticar a criação de formulários HTML, utilizar diferentes
tipos de campos, aplicar validações nativas e utilizar o Bootstrap para
organizar e tornar a página responsiva.

## Tecnologias utilizadas

- HTML
- CSS
- Bootstrap 
- JavaScript
- GitHub Pages

## Tipos de input utilizados

- text: entrada de texto.
- email: entrada de endereço de e-mail.
- password: entrada de senha ou código.
- number: entrada de números.
- tel: entrada de telefone.
- url: entrada de endereço de site.
- search: campo de pesquisa.
- date: seleção de data.
- month: seleção de mês.
- week: seleção de semana.
- time: seleção de horário.
- datetime-local: seleção de data e horário.
- color: seleção de cor.
- range: seleção de um valor em uma escala.
- file: envio de arquivo.
- checkbox: seleção de múltiplas opções.
- radio: seleção de uma opção entre alternativas.
- hidden: armazenamento de uma informação que não aparece visualmente.
- submit: envio do formulário.
- reset: limpeza dos campos.
- button: botão comum.
- image: botão de envio utilizando uma imagem.

## Investigação

### Qual a diferença entre radio e checkbox?

O radio é utilizado quando o usuário deve escolher apenas uma opção
dentro de um grupo. O checkbox permite selecionar várias opções.

### Para que serve o atributo required?

O atributo required determina que o campo precisa ser preenchido antes
que o formulário possa ser enviado.

### Para que serve o atributo pattern?

O pattern permite definir um padrão que o valor do campo deve seguir,
sendo útil para validações como números de telefone.

### Para que servem min, max e step?

Esses atributos permitem definir o valor mínimo, máximo e o intervalo
de valores aceitos em campos numéricos.

### Para que serve accept no input file?

O atributo accept permite indicar quais tipos de arquivos podem ser
selecionados pelo usuário.
